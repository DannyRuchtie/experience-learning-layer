Extract durable evidence from the following user message.

Rules:
- Extract only meaningful claims, preferences, goals, decisions, corrections, or facts.
- Do NOT extract personality traits, jokes, or one-time casual remarks.
- Do NOT turn temporary requests into lasting preferences.
- Return an empty list [] when no durable evidence exists.

Message: {message_text}

Return a JSON array of evidence objects with these fields:
- id (UUID)
- message_id (UUID)
- type: one of FACT, PREFERENCE, GOAL, BELIEF, DECISION, CORRECTION, OUTCOME, BEHAVIOUR, RELATIONSHIP, PROJECT_KNOWLEDGE, INSTRUCTION
- statement: the normalized claim
- subject: what this is about
- temporal_scope: MOMENTARY, SESSION, PROJECT, ONGOING, or UNKNOWN
- importance: 0.0-1.0
- extraction_confidence: 0.0-1.0
- supporting_excerpt: short excerpt from the original message
