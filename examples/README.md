# Synthetic lifecycle examples

`golden-cases.jsonl` is synthetic and contains no imported personal data. Each case isolates
one policy or lifecycle behavior: explicit learning, review quarantine, unsupported
claims, sensitive inference, correction, contradiction, temporal change,
multilingual evidence, and prompt injection treated as source content.

The examples are illustrative inputs for the paper, not benchmark results or proof
of a working implementation. A future evaluation harness may adopt and version
them once its validation contract is defined.
